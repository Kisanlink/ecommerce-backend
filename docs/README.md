# Copilot Instructions – Quick Guide

This folder contains all **instruction prompts** for GitHub Copilot.  
Keep the correct file open while coding to guide Copilot’s suggestions.

---

## 📌 When to Open What

- **Creating a new Model**  
  Open 👉 `COPILOT_MODELS.md`

- **Building Repository / Service Layer**  
  Open 👉 `COPILOT_REPOSITORIES.md`

- **Writing API Handlers (Requests/Responses)**  
  Open 👉 `COPILOT_REQUESTS.md`

- **End-to-End Feature (Model → Repo → Service → Handler)**  
  Open 👉 `COPILOT_COMPLETE_EXAMPLE.md`

- **Database-specific patterns**  
  Open 👉 `COPILOT_DATABASE.md`

---

⚡ **Pro Tip:**  
- Always keep only the relevant `.md` file open when working.  
- Copilot will automatically learn from it and follow your conventions.
